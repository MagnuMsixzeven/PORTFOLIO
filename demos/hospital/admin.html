Sobre as Database Functions (Triggers)
trg_proteger_prioridade
Impede alteracao do campo prioritario em qualquer senha ja emitida. Apenas usuarios com papel recepcionista ou admin podem alterar. Bloqueia e reverte o estado no cliente.
trg_audit_fila
Registra automaticamente cada exclusao de senha e cada mudanca de status (esperando → chamado → finalizado) com IP e ID do usuario responsavel.
trg_audit_medicos
Registra automaticamente cada remocao de medico da tabela fila_medicos, preservando nome, CRM e IP da operacao.

Mensagem para apresentacao
O sistema esta sendo preparado para integracao com plataformas de terceiros, permitindo troca de dados e automatizacao entre empresas parceiras.
Novas integracoes poderao contemplar cadastro compartilhado, sincronizacao de filas, importacao de dados e comunicacao por API.
Cada parceria tecnica sera validada conforme requisitos, seguranca dos dados, disponibilidade da outra empresa e escopo comercial aprovado.

Sistema de agenda

Sincronizar dados operacionais, unidades, convenios, faturamento e controles administrativos.
Painel corporativo
Compartilhar metricas, chamadas, alertas e indicadores com outras plataformas institucionais.
